# Python 脚本合集

个人 Python 脚本仓库，包含爬虫、视频/音乐下载、数据挖掘等练习项目。

## 内容概览

### 爬虫
- **豆瓣 Top200** — 豆瓣电影排行爬取
- **当当网 Top500** — 当当网图书排行爬取
- **B站视频下载** — 获取B站视频（`get_bilibili_video.py`、`bilibili_cxk_lq.py`）
- **抖音** — 抖音视频下载与JSON数据解析（`get_douyin_video.py`、`douyin_json.py`、`douyin_text.py`）
- **腾讯视频** — 视频下载与VIP视频获取（`get_tcent_video.py`、`get_tencent_002.py`、`get_tencent_vip_video.py`）
- **笔趣阁** — 小说下载与文本提取（`biquge_xiaoshuo.py`、`biquge_text.py`）
- **酷狗音乐** — 音乐下载（`get_kugou_music.py`）
- **花猫壁纸** — 图片爬取（`get_huamaobizhi_jpg.py`）

### 工具
- **MD5加密** — 字符串MD5加密
- **IP查询** — IP地址查询（`get_ip.py`、`get_ipadrress.py`）
- **正则表达式** — `re`库用法示例

### 数据挖掘（课程作业）
- Pandas 数据处理
- Matplotlib 可视化
- Scikit-learn 机器学习
- 决策树、SVM
- 拉格朗日插值

### 其他
- 自动测试脚本
- 京东红包

## 环境要求

- Python 3.x
- pip install requests beautifulsoup4 pandas matplotlib scikit-learn openpyxl
